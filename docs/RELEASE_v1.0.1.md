## 갤럭시 카메라 무음 v1.0.1

PC에 갤럭시를 연결하고 버튼 한 번으로 카메라 셔터음 강제 설정을 해제하는 Windows 프로그램입니다.
루팅도, 휴대폰 앱 설치도, PC 설치도 필요 없습니다.

### 라이선스
개인 사용은 무료입니다. 소스 코드는 투명성을 위해 공개하지만 오픈소스가 아니며,
수정·재배포·상업적 이용은 허락하지 않습니다. 자세한 내용은 [LICENSE](../../blob/main/LICENSE) 를 참고하세요.

### 다운로드
- **GalaxyCameraMute.exe** — 프로그램 (약 15.5MB, Windows 10 / 11)
- **갤럭시 카메라 무음 사용설명서.pdf** — 사진이 들어간 27쪽 설명서

### 기능
- 케이블을 꽂으면 기기를 자동으로 찾아 목록에 표시 (4초 간격)
- 연결된 모든 기기에 일괄 적용, 또는 원하는 기기만 선택
- 기기별 현재 상태(무음 / 셔터음 켜짐) 표시, 적용 후 값을 다시 읽어 확인
- [셔터음 원복]으로 언제든 되돌리기
- 빅스비 루틴 함께 추가: 카메라를 켜면 소리 모드 무음, 끄면 원래대로
- USB 디버깅 켜는 법을 실제 갤럭시 화면 사진 8단계로 안내
- adb는 동봉하지 않고 첫 실행 때 Google 공식 서버에서 받아 exe 옆에 저장
- 다크 / 라이트 테마

### 처음 실행할 때
'Windows의 PC 보호' 창이 뜨면 **[추가 정보] → [실행]** 을 누르세요.
코드 서명이 없는 개인 제작 exe라서 나오는 경고입니다.
